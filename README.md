# Draw

A simple drawing application created by [hos8](https://github.com/hos8).

## Overview

Draw is a lightweight application that allows users to create digital drawings with various tools and options. Ideal for quick sketches, diagrams, or simple artwork.

## Features

- **Multiple Brush Types**: Choose from pencil, marker, or eraser.
- **Color Picker**: Select from a palette or use a custom color.
- **Canvas Customization**: Adjust canvas size and background.
- **Save & Export**: Save your drawings in common formats (PNG, JPEG).
- **Undo/Redo**: Easily correct mistakes with undo and redo functionality.

## Installation

### Prerequisites
- Node.js (v14 or later)
- npm or yarn

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/hos8/draw.git
   ```
2. Navigate to the project directory:
   ```bash
   cd draw
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm start
   ```

## Usage

1. Open the application in your browser (default: `http://localhost:3000`).
2. Use the toolbar to select brushes, colors, and other options.
3. Draw on the canvas by clicking and dragging.
4. Save your work using the "Export" button.
